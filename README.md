# ChemAI_Predict_the_Cure
## Задача разработки модели, предсказывающей эффективность новых соединений лекарственных препаратов против вируса гриппа.
### Описание задачи:
Разработка новых лекарственных препаратов — сложный и длительный процесс, включающий синтез соединений и их биологическое тестирование. 
Современные методы машинного обучения позволяют ускорить этот процесс, 
предсказывая эффективность химических соединений до проведения лабораторных экспериментов.

### **Цель:** Построить модели, способные предсказывать эффективность новых соединений лекарственных препаратов против вируса гриппа.


### **Описание данных**
Имеются данные о свойствах молекул и их биологической активности против вируса гриппа.

### **Задача:** Для каждого химического соединения необходимо предсказать три показателя:
- `IC50 (mM)` — концентрация, при которой вещество подавляет 50% активности вируса
- `CC50 (mM)` — концентрация, при которой вещество токсично для 50% клеток
- `SI (Selectivity Index)` — индекс селективности.

### **Метрика:**
Задача оценивается по метрике RMSE (Root Mean Squared Error), усреднённый по трём таргетам:

$$
\text{score} = \frac{\text{RMSE}(\text{IC50}) + \text{RMSE}(\text{CC50}) + \text{RMSE}(\text{SI})}{3}
$$

Где:
- **RMSE(IC50)** — корень из среднеквадратичной ошибки для IC50
- **RMSE(CC50)** — корень из среднеквадратичной ошибки для CC50  
- **RMSE(SI)** — корень из среднеквадратичной ошибки для SI
