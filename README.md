# ChemAI: Predict the Cure

## Задача разработки моделей, предсказывающих эффективность новых соединений лекарственных препаратов против вируса гриппа.

### Описание задачи:
Разработка новых лекарственных препаратов — сложный и длительный процесс, включающий синтез соединений и их биологическое тестирование. 
Современные методы машинного обучения позволяют ускорить этот процесс, 
предсказывая эффективность химических соединений до проведения лабораторных экспериментов.

### **Цель:** Построить модели, способные предсказывать эффективность новых соединений лекарственных препаратов против вируса гриппа.

### **Описание данных**
Имеются данные о свойствах молекул и их биологической активности против вируса гриппа.

### **Задача:** Для каждого химического соединения необходимо предсказать три показателя:
- `IC50 (mM)` — концентрация, при которой вещество подавляет 50% активности вируса
- `CC50 (mM)` — концентрация, при которой вещество токсично для 50% клеток
- `SI (Selectivity Index)` — индекс селективности.

### **Метрика:** RMSE (Root Mean Squared Error), усреднённый по трём таргетам:
$$
\text{score} = \frac{\text{RMSE}(\text{IC50}) + \text{RMSE}(\text{CC50}) + \text{RMSE}(\text{SI})}{3}
$$

Где:
- **RMSE(IC50)** — корень из среднеквадратичной ошибки для IC50
- **RMSE(CC50)** — корень из среднеквадратичной ошибки для CC50  
- **RMSE(SI)** — корень из среднеквадратичной ошибки для SI

## Описание подхода
### Этапы решения
1. **Исследовательский анализ данных (EDA)**
   - Выявлены выбросы и сильная асимметрия в распределении целевых переменных.
   - Обнаружена высокая корреляция между некоторыми признаками и мультиколлинеарность.
   - Установлен различный масштаб значений признаков.
2. **Предобработка данных**
   - Выполнено логарифмическое преобразование целевых переменных для нормализации распределения (`pIC50`, `pCC50`, `log_SI`).
   - Пропуски в данных заполнены средними значениями.
   - Проведено масштабирование признаков.
   - Выполнен отбор информативных признаков для снижения размерности и влияния мультиколлинеарности.
3. **Моделирование**
   - Для автоматизации процесса и поиска сильного бейзлайна использована библиотека **AutoGluon Tabular** (Amazon).
   - AutoGluon позволил:
     - Автоматически протестировать различные алгоритмы машинного обучения;
     - Сравнить модели и выбрать лучшие;
     - Построить ансамбли (Stacking и Bagging) для повышения качества предсказаний.
   - Финальное решение — взвешенные ансамбли моделей (WeightedEnsemble), показавшие наилучшие результаты на валидации.

4. **Результаты:**
   - Разработанный пайплайн обеспечил высокое качество предсказаний по всем трем целевым переменным.
   - **Итоговый RMSE-score на лидерборде Kaggle: 295.24**

### Ключевые особенности решения
- **Минимум ручной настройки**: AutoGluon автоматизировал подбор моделей и гиперпараметров, позволив команде сосредоточиться на анализе данных и улучшении признаков.
- **Устойчивость к выбросам**: Логарифмирование таргетов и использование робастных ансамблевых методов снизило влияние аномальных значений в данных.
- **Воспроизводимость**: Полный пайплайн обучения сохранен и может быть воспроизведен.
